# Sleep and Doomscrolling Analysis

## Project Overview
This project analyses the relationship between doomscrolling habits, bedtime screen time, and sleep patterns.

## Dataset
The project uses the Sleep and Doomscrolling Habits Dataset in CSV format.

## Tools
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Files
- D2_Sleep_Doomscrolling_Analysis-2.ipynb: Data analysis and cleaning workflow.
- sleep_doomscrolling_habits.csv: Original dataset.

## Workflow
The notebook imports, inspects, validates, cleans, transforms, and prepares the data for visualization.

## Limitation
The dataset contains synthetic observations and does not represent verified responses from real students.
